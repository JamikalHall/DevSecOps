Day 11: Revisiting the Basics

Completing the learntocloud.guide curriculum. Finished Phase 0 as a refresher.

Big Ideas:

- **What is DevOps** - The joining of developer focused efforts and operation focused efforts. The process of going from idea -> code -> build -> deploy -> manage/monitor -> learn -> repeat
- **Version Control** - the ability to track changes over time. It provides the ability to see change history, and see what the state of your code/file was at any given time.
- **Infrastructure As Code** - The idea that your infrastructure (the stuff that your code runs on) can be automated and have version control applied to it. The focus is on Reusability, Versioning, and automation.
- **Continuous Integration/Continuous Deployment** - the idea that you can constantly integrate new code and deploy with minimum to no downtime.
- **Observability** - the ability to make conclusions about a system based on it's telemetry. Observability relies on logs, traces, and metrics.
- **Containers** - a single unit of software containing all the code and its dependencies in one package. This ensures the package can run reliably from one environment to the next.
- **Kubernetes** - a management platform for containers.
